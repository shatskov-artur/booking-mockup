Строим сайт с онлайн-записью для мастера маникюра в Польше. Это первый коммерческий проект —
реальный клиент (знакомая), не учебный. Работаем с нуля в этой папке.

## Контекст клиента

Мастер маникюра, работает в Польше. Сейчас клиенты приходят только по сарафанному радио,
за Booksy платит 200 zł/мес и хочет уйти с него. Записи ведёт вручную.

ВАЖНО: её реальный прайс и список услуг ЕЩЁ НЕ СОБРАНЫ — интервью с ней не проводилось.
Поэтому на услуги/цены ставим правдоподобные заглушки (типовые польские цены на маникюр
классический, гель-лак, наращивание, педикюр) и делаем так, чтобы их можно было заменить
в ОДНОМ месте — потом подставим реальные. Не зашивай цены по всему коду.

## Что нужно в первой версии (для оценки — показать клиенту)

Публичная часть, одностраничник:
- услуги с ценами и длительностью
- галерея работ
- форма записи: выбор услуги → дата/время → имя + телефон
- контакты + карта

Админка, отдельный экран:
- список записей (сегодня/неделя), возможность отменить/подтвердить

## Стек

Обсудить со мной перед началом. Предварительно обсуждалось: Next.js + Supabase (регион
eu-central) + Vercel — Supabase даёт БД, auth и хостинг данных в ЕС из коробки, что важно
для RODO. Но я хочу проговорить варианты, а не принять по умолчанию — предложи альтернативы
с плюсами/минусами, если видишь лучше.

## RODO — обязательно с первого дня

Клиентка будет принимать персональные данные реальных людей (имя, телефон). Поэтому сразу:
- галочка согласия на обработку данных в форме записи (не предустановленная)
- страница/блок политики приватности: кто контролёр данных, зачем собираем, срок хранения
- данные хранятся в ЕС (отсюда регион eu-central)
- возможность удалить запись/данные

Это не бюрократия — это то, что отличает продаваемый продукт от учебного, и потом
прикручивать в разы дороже.

## Как работаем

Этапный цикл: обсуждение → план с Definition of Done → работа → проверка по DoD → ретро.
Сначала обсуди со мной объём и стек, потом план, и только потом код. Definition of Done
для первой версии: локально запускается, форма записи создаёт запись в БД, запись видна
в админке, RODO-согласие есть.

Мой уровень: ~2 года коммерческого опыта, AI & Automation Engineer. Уверенно: JS/TS, React,
Node, PostgreSQL, n8n, интеграции API. Слабее: Next.js, Tailwind, тестирование — их изучаю
на ходу, объясняй решения по ним чуть подробнее.
