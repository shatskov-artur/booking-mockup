# Studio Paznokci — макет сайта с онлайн-записью

Кликабельный макет сайта для мастера маникюра. Статические файлы, без бэкенда:
открывается двойным кликом по `index.html` или по ссылке GitHub Pages.

**Это макет.** Записи никуда не отправляются, данные клиенток выдуманные.

## Ссылки

- Публичная страница: `index.html`
- Панель мастера: `admin.html` — **пароль: `paznokcie2026`**

Пароль лежит в [data.js](data.js) в открытом виде и виден в исходнике страницы.
Он не защищает данные — нужен только чтобы случайный посетитель по ссылке
не попал в панель. Настоящая авторизация появится в версии с бэкендом.

## Что можно потрогать

**Публичная страница**
- Услуги с ценами и длительностью
- Галерея работ
- Запись: услуга → день → время → имя и телефон → согласие RODO
- Контакты, политика приватности
- 5 цветовых тем и 3 языка (PL / RU / UA) — переключатели в шапке

**Панель мастера** (4 раздела)
- **Wizyty** — список записей: сегодня / неделя / месяц / отменённые.
  Календарь загруженности с цветами, перенос записи, добавление вручную,
  подтверждение и отмена, удаление данных (RODO)
- **Galeria** — загрузка фото с телефона, названия, привязка к услуге,
  архив, порядок стрелками
- **Usługi** — цены, длительность, включение/выключение услуги
- **Grafik** — часы работы по дням недели, отпуска и перерывы

## Важно про данные

Цены, услуги, имена клиенток и контакты — **заглушки**. Реальный прайс
подставляется правкой массива `SERVICES` в [data.js](data.js), контакты —
объекта `SALON` там же. Всё в квадратных скобках (`[IMIĘ NAZWISKO]`,
`[ULICA I NUMER]`) заполняется перед публикацией настоящего сайта.

Правки, сделанные в панели (фото, цены, график), сохраняются в браузере
через `localStorage` — у каждого свои, на других устройствах их не видно.
Обновление страницы их не сбрасывает, очистка данных браузера — сбрасывает.

## Структура

```
index.html    публичная страница
admin.html    панель мастера
styles.css    все стили, 5 тем на CSS-переменных
data.js       услуги, цены, контакты, график, пароль — ЕДИНСТВЕННОЕ место
i18n.js       все тексты на трёх языках
app.js        логика: календарь, слоты, формы, галерея
```

## Проверено

Реальный Chrome, эмуляция тач-устройств: iPhone SE (375px), iPhone 13 (390px),
Android (412px), планшет и десктоп до 1440px. Все 5 тем проходят контраст
WCAG AA, три языка без непереведённых строк, горизонтального скролла нет.

На телефоне перетаскивание не работает нигде в вебе, поэтому везде есть
альтернатива нажатием: перенос записи — кнопка «Przełóż», порядок фото — стрелки.
